##  Functional Requirements

### FR-01 — Report Maintenance Fault

The system shall allow an authenticated student to submit a maintenance fault
for their assigned room by providing a description of the problem and the
required room information.

### FR-02 — Create Maintenance Ticket

The system shall create a unique maintenance ticket when a valid maintenance
fault report is submitted.

### FR-03 — Validate Fault Report

The system shall validate required maintenance report information before
creating a maintenance ticket.

### FR-04 — Verify Maintenance Report

The system shall allow an authorised Student Welfare Officer to review and
verify a submitted maintenance ticket.
